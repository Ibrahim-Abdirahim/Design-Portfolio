# JESNet — Jamhuriya English Skills Network

A collection of graphic design work I created for the Jamhuriya English Skills Network (JESNet), a student organization at Jamhuriya University.

## Design Work

This folder contains selected designs created for JESNet, including promotional graphics, event materials, and social media content.
